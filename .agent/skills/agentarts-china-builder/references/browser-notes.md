# 浏览器实操与故障处理

这里只保留2026-10-30中国站控制台中影响搭建的已遇问题；选择器会随平台升级变化。先看当前快照／DOM，确认元素用途后再操作，不把历史 ref 或节点ID当固定契约。

## 已登录浏览器与登录问题

- 本次真正登录成功的是 Playwright 控制的 Chrome；内置浏览器的旧登录标签仍停在认证页。要检查各个实际标签，不能因为用户在一个窗口登录，就认为其他上下文也继承登录。
- 用户本轮明确选择**华为云账号的华为云APP扫码**，优先级高于之前关于“华为账号”的记录。`HUAWEI ID / 华为账号`会跳往另一套身份页面，不能因为它也有二维码就交给用户扫描。`id*.cloud.huawei.com`页面要求手机控制中心／华为账号“扫一扫”，与本目标不同。
- 若普通浏览器稳定、自动化连接不可用，可让用户完成正常登录或改用当前可操作窗口；不要导出认证状态，也不要用持续重试解决风控提示。

### 华为云 APP 扫码的实测路径与边界

1. 正常进入中国站AgentArts，检查是否已有有效会话。有会话就核对账号／区域并保留，不为测试主动退出。
2. 未登录落到 `auth.huaweicloud.com/authui/login.html#/login` 时，选择“更多账号登录 / More”，然后“华为云账号 / Huawei Cloud Account”；不要点紧邻的“华为账号 / HUAWEI ID”。在2026-10-30页面中，前者进入 `#/login2`，后者另开身份标签。
3. 在华为云账号页选择右上角“扫码登录”。确认**二维码图片确实渲染**，且旁边是“请使用华为云APP扫描二维码登录”；检查该页 `service` 唯一指向 `https://console.huaweicloud.com/agentarts/`、区域 `cn-southwest-2`。二维码倒计时和图片是瞬态内容，不保存其编码或把截图传到Git。
4. 用户扫码并在手机确认后，观察实际跳回中国站控制台，核对目标账号、区域与应用内容。本轮当前主会话已实测成功，并只读重开原C01草稿确认3个节点、2条连线仍在，没有试跑、发布或新增资源。
5. 全新未登录上下文的探测证实：默认界面可能英文；语言菜单需点击展开，选择简体中文后重新观察。即使进入 `#/login2` 并带 `quickLogin=true`，二维码切换也可能在配置加载后消失，只留下账号表单与升级提示。该情况**没有验证成可无人干预到达二维码**；应停止并交接缺口，不能把初始短暂出现的“扫码登录”文字当已就绪或绕过页面限制。

本轮人机协作登录成功，不等于任意新设备、网络、浏览器配置都能无条件完成登录。顶部／页脚偶尔出现intl链接时，不能只按界面语言或品牌判断站点；仍须核对真实域名、service回跳目标以及扫码后的实际账号、区域和控制台内容。

官方说明：[登录华为云与扫码方式](https://support.huaweicloud.com/usermanual-account/account_id_004.html)。页面当前选择与用户指示优先；文档或旧表单的“账号升级”说明不授权自动改换登录体系。

## 视口、缩放和面板

- Chrome曾处于25%缩放，导致页面坐标、视口宽度和截图表现异常；网页中的 `Control+0` 未生效，使用正常浏览器的缩放菜单／原生快捷键恢复100%后才正常。先检查实际缩放，不因点击不准重复重登。
- 原生窗口和网页视口是不同对象。只有工具实际可访问浏览器窗口时才调整浏览器缩放；不要修改其他应用。截图要实际查看，确认目标控件确实在视口。
- 画布节点在视口外时，优先使用底部自动布局／居中／缩放控件；这与浏览器缩放不同。点“代码”文本需双击才能打开节点配置。
- 平台可能把HTML节点嵌在SVG foreignObject里，Playwright `locator('body')`会匹配多个body；本次读取外层页面使用 `locator('body').first()`，图操作限定 `#app-flow-container`，排除小地图副本。
- 本次代码／结束配置面板为 `#flow-common-half-modal`，节点测试为 `#flow-node-exe-id`，整图试运行为 `flow-run-modal`。先验证当前DOM仍对应这些面板，再使用；遇到“问题清单”遮挡先读取问题，修复实际字段。

## 长JSON输入与Monaco代码

普通JSON输入框可能在长文本进入后重新渲染成textarea；原先input上的填写可能丢失。重新获取当前可见控件，填入后失焦，再次读取值确认长度和内容。不要填完立刻无条件点击开始运行。本次整图参数框的可访问名称为“请输入 query”；节点测试中的输入控件不同。

Monaco的逐字插入曾引起自动缩进与引号配对；给编辑器整体fill也未可靠保留源码。对本项目已审阅代码，可以使用正常“全选→清空→粘贴”：

```javascript
// 当前环境确有Playwright、该编辑器已定位并确认后使用。
const editor = page.getByRole('textbox', {name: 'Editor content', exact: true});
await editor.press('ControlOrMeta+A');
await editor.press('Backspace');
await page.evaluate(text => navigator.clipboard.writeText(text), reviewedCode);
await editor.press('ControlOrMeta+V');
```

`reviewedCode`来自本地已审阅源码，不含秘密；这不是读取用户剪贴板。工具不支持该方法时改用编辑器正常粘贴界面，不读取隐藏的Monaco模型或注入组件内部状态。粘贴后检查首尾、缩进、入口及输出，关注配置保存状态；编辑器清空后粘贴失败时不要运行空代码。

## 连线、引用与保存

- 优先使用正常节点菜单或DOM定位的端口拖拽；获取端口当前包围盒再拖动，不能用过期坐标或修改X6内部Graph对象。本次代码菜单有“连接到结束节点”；开始到代码通过可见端口连接。
- 引用树为空时先检查连线。选择“开始”或“代码”一级分组后点其输出字段；仅悬停未展开。本例代码输入引用开始.query，结束输入引用代码.result。
- 节点面板测试图标会校验配置并打开测试面板，不等于已执行；只有进一步点击“开始运行”才发起本次测试。完整图可能校验到其他节点的错误，例如删除大模型后结束仍引用旧raw_output。
- 配置校验和试运行入口涉及异步重渲染。等待预期新面板／字段出现，再重新定位，不复用旧的自动生成ID。关闭无效面板可能丢失修改。
- 顶栏和整图试运行面板都可能有“试运行”文字，按banner或目标面板限定选择器，避免严格模式多匹配。

## 运行中、导出失败和重试

- 开始运行后先读最终状态。超时或连接中断时，查看当前结果、调用详情和已有运行记录，核实完成／仍在运行／失败；状态未知不重新点一次。不要把本地工具超时当作云端未收费的证明。
- 本次原生“导出”跳转到平台OBS签名地址后 `ERR_TIMED_OUT`，没有下载文件。不要在日志或Git里保存签名URL，不宣称已有原生包；代码和公开输入仍可按仓库步骤重建。
- 只在查明原因、预算允许且操作仍获授权时做有理由的重试；不因新建草稿或换浏览器而重置团队支出。遇到持续身份、权益、计量或访问问题，保留具体阻碍和继续位置，先做本地工作。
