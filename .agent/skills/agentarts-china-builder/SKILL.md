# AgentArts 中国站搭建

按用户指定的研究任务操作真实控制台，交付可复现的工作流、可核对的实际结果和明确的接入边界。优先复用已验证的 C01 工具；新增模型、研究编排或发布渠道时，分别取得对应证据。

## 入口与适用环境

- 本 skill 位于产品根目录 `.agent/skills/agentarts-china-builder/`。从本文件所在目录向上三级即产品根；先读根目录 `AGENTS.md`、`docs/README.md`。
- 已验证工具的权威源码、公开输入、配置、数据署名与预期数值在根目录 [agentarts/c01-sensitivity/README.md](../../../agentarts/c01-sensitivity/README.md)。本 skill 不复制一套代码或固定结果。
- 浏览器工具因开发环境而异：先发现当前可用的标签列表、DOM／快照、点击、输入、截图能力。复用用户已登录的正确标签；避免同时由多个 Agent 操作同一页面或草稿。
- 正确的中国站入口为 [AgentArts 控制台](https://console.huaweicloud.com/agentarts/?region=cn-southwest-2#/home/overview)。确认实际域名、区域、账户和目标工作流；`auth.huaweicloud.com` 是该入口跳转的官方认证域名。不要把中文界面、代理出口或空白登录页直接当作国际站证据。

本路径由用户指定，**仅放在 `.agent/skills/` 不保证开发工具自动发现**。无法直接调用 `$agentarts-china-builder` 时，让队友的 Agent 先读取本 `SKILL.md`；安装到各工具约定的技能目录是另一个可选操作，不自动改队友环境。

## 开始前：身份、费用与对象

1. 检查是否已登录。已登录正确账户及区域时保留会话，不退出重登。未登录时走下方**华为云账号 → 华为云APP扫码**流程；除非用户改变选择，不切换成华为账号/HUAWEI ID、密码或短信方式。不用收集 Cookie、密码、密钥或保存浏览器状态。
2. 打开当前控制台的“套餐用量”。记录套餐、有效期、CU和模型剩余额度、已建应用及资源，再核对 [计费项](https://support.huaweicloud.com/price-agentarts/agentarts_08_0003.html) 和 [免费额度](https://support.huaweicloud.com/price-agentarts/agentarts_08_0001.html)。免费CU、模型Token、代码解释器会话和Runtime实例不是同一预算。
3. 查明本轮已授权的操作和团队累计现金上限。ICT当前沿用新增现金合计 **5元** 的既有边界；不能给每位队友、每次重试或新目录另算5元。向主控索取 ignored `.agent/team-budget.json` 的最新脱敏记录；新clone没有这份本机记录是正常情况，不能自行按0元开始。此前显示的20 CU只是历史观察，不能当新额度或最终账单。成本／已消耗额不清楚时可以继续只读检查和本地准备，不执行可能超限的调用。
4. 列出现有草稿和版本；同一个负责人继续自己的草稿，避免重复创建。独立复现由队友使用各自命名的副本，不覆盖共享草稿。准备改变共享草稿时确认当前操作者和目标ID。

## 登录接管：默认华为云 APP 扫码

```text
中国站入口 → 已登录且账户/区域已核对 → 只读检查目标草稿
           → 未登录 → 更多账号登录 → 华为云账号 → 扫码登录
                    → 确认“请使用华为云APP扫描二维码登录”和真实二维码
                    → 等用户扫码及手机确认 → 核对回到中国站控制台 → 只读检查
任意异常、二维码缺失、风控、状态不明 → 停止该分支并保留继续位置
```

- 必须识别页面的**华为云APP**扫码说明；华为账号页面的“手机控制中心／设置→华为账号→扫一扫”属于另一条入口，不能作为本任务的成功状态。
- 默认页可能是 `#/login`，从“更多账号登录 / More”选择“华为云账号 / Huawei Cloud Account”进入 `#/login2`，再使用右上角正常的扫码切换控件。英文界面先用页面语言菜单切至简体中文，随后重新获取控件，不复用旧ref。
- `quickLogin=true#/login2` 只作为已观察到的官方页面模式参考，保留并核对 `service` 指向中国站AgentArts。不能用它保证二维码出现，也不伪造登录结果。实际步骤与缺失处理见 [浏览器实操](references/browser-notes.md)。
- 二维码有效时等待人工扫码，不代填密码、验证码，不替用户在手机确认。已扫码但待手机确认仍是等待状态。二维码过期先重新观察；用户准备好后可用页面正常刷新一次，不能循环刷新或重试风控。
- 登录成功至少核对 HTTPS精确域名 `console.huaweicloud.com`、`/agentarts/` 路径、`region=cn-southwest-2`、真实控制台内容、目标账号与区域。二维码消失、用户口头说“已登录”、URL出现console字样都不能单独当成功。再打开已有目标草稿确认可读，不触发试跑或发布。
- 遇到风险提示、验证码、空白页或缺失二维码入口时安全停下，不自动切到另一账号体系、不修改风控脚本或代理。无需为了测试退出用户已有登录；新环境探测使用独立临时上下文，结束仅关闭自己创建的上下文。

需要可重复判定时，用 [scripts/handoff_gate.py](scripts/handoff_gate.py) 对浏览器**实际观察**的最小JSON做只读检查；观察字段格式见脚本docstring。它不连接浏览器、不读取会话、不执行登录；通过只表示可继续只读核对，永远不授予运行／发布权限。运行 [负例测试](scripts/test_handoff_gate.py)：

```powershell
.venv/Scripts/python.exe -B .agent/skills/agentarts-china-builder/scripts/test_handoff_gate.py -v
```

## 搭建已验证的专业工具

按 [C01工具说明](../../../agentarts/c01-sensitivity/README.md) 逐项配置。最小图为：

```text
开始.query:String → 代码.query（引用开始.query）
代码.result:String → 结束.result（引用代码.result）→ 指定回复 {{result}}
```

- 新建任务型工作流时先检查默认大模型节点；纯计算路径移除它，再连开始→代码→结束。不要在图仍包含未核验模型时直接整图试跑。
- 本例复制仓库完整 `code_node.py`，保持已验证的 `main(args: dict)` 入口及函数内导入／辅助函数形态。不要仅为本地风格重构沙箱代码。代码节点不等于平台“代码解释器”会话。
- 先完成连线再选择上游引用；未连通的上游可能不出现在引用树中。选择树中的“开始”或“代码”后，再点具体 `query` 或 `result`。
- 超时10秒、不重试、异常中断流程是本例的设置。字段类型和返回字典键必须一致；关闭面板不一定代表配置有效或已保存。检查错误清单与“保存于”时间。
- 编辑器旁的模型是AI辅助入口，不需要点击它来执行已有Python。本例计算不调用模型；不要顺手生成代码或开启额外工具。

遇到输入丢失、编辑器缩进、节点不在视口、引用为空或导出失败时，按需读 [浏览器实操与故障处理](references/browser-notes.md)，不盲目复试。

## 验证与留证

先本地运行工具说明中的测试，再做任务所需的最少云端执行。只为独立复现时一次8样本完整工作流即可；本地单测不是云端结果，节点测试也不是整图执行。

1. 输入公开JSON，先确认字段实际保留了内容，再开始运行。以最终状态判断；工具调用超时并不等于云端失败，先看原运行结果，不立即重发。
2. 在运行结果核对样本数、canonical输入SHA、数值、状态和限制；按工具说明容差逐项对照。在调用详情查看实际节点和耗时，不能只看绿色对勾。仅在任务确实需要证明输入引用时，才额外用事先约定的公开子集验证输入改变。
3. 记录源码commit／本地文件SHA、草稿ID、平台版本（如可见）、运行时间、实际输出和平台运行标识（如可见）。没有Trace ID就写未取得；手工复制的JSON标记为控制台输出摘录，不冒充原生导出包。
4. 复查用量及本任务所建资源状态；停止仍在执行的本任务调用，释放按任务批准创建的临时会话。保留供后续协作的开发草稿；不要删除他人资产。未启动常驻资源时无需为了清理而购买或启用资源。
5. 证据放在产品 ignored `runs/<本轮>/` 或 `.agent/artifacts/<本轮>/`，截图与摘录脱敏，不入Git。重开草稿确认节点、引用和已保存配置仍在，再交接给队友。

## 让研究 Agent 调用工具

只有用户任务包含这一层时才继续：先读 [架构边界](../../../docs/architecture.md) 和现行官方平台文档，核对当前界面是否支持所需工作流工具／子工作流接入。不要依据旧截图猜模型字段、API或发布步骤。

将工具输出作为观察，要求决策返回受限的“继续、修订、停止／人工复核”及依据；给出模型请求次数和费用预留上限。先做一次有界调用，核对真实模型请求、真实工具反馈和决策依据，再验证写回研究账本。UI连线、角色名称、脚本分支或模型复述不能代替这些证据。

C01的 `needs_review` 不能被模型润色成成功；`exploratory_only` 也不是科学验证通过。单合金删除是事后诊断，不能为了较好结果自动剔除样本。真实LLM决策、本地C01Loop/ResearchLoop连接、持久记忆、发布API及高代码Runtime分别验收，不从代码沙箱成功推导。沿用已有授权，涉及新持久凭据、权限扩大或发布时检查该具体动作是否已获授权。
