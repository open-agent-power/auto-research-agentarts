### hiMSC 的红色强度标签存在数列角色冲突

独立复核全部 12 个 section，共 **3312/3312** 个 `_Normalised!E` 值，均与对应 `_SNR` 的 **Std Cell Count ÷ 同 section 平坦基底的 Std Cell Count** 一致。

一个可手算的原坐标例子：

```text
hiMSC_Raw_Data.xlsx
B8S1_Normalised!E2  （Avg Red Intensity）= 0.6756492790031468
B8S1_SNR!E2        （Std Cell Count）   = 20.441787266935997
B8S1_SNR!E82       （flat Topo1/Chem0） = 30.25502713048968
E2 / E82 = 0.6756492790031468

B8S1_SNR!G2 / G82 （Avg Red Intensity 的平坦基底比）= 1.3365449385299482
```

不是只按列名猜测：原始计数按键复算的样本标准差也与 `_SNR!E` 一致。这 3312 个值继续进入 `RedIntensityAllBatches`；按键取非空 section 值均值后，又与 `DataForClustering!H` 的 980/980 项一致（浮点容差内）。处理层是硬编码数值，没有公式链可作为标签裁决依据。

因此保留原始数值和标签，标记 **endpoint role conflict**。这不裁定复制方向、作者图表或科学结论是否错误，也不能将标准差关系直接换名为 ALP。用这列训练会得到不具备当前生物学解释的演示成绩。

### 重复、缺失和归一化也需保留

- `_Normalised` 的计数列与 `_SNR` 平均计数直接一致，并非都已除平坦对照。汇总表均值与样本 SD 可复算，但这不证明“归一化计数”的生物口径。
- hiMSC 聚合是所有非空 section 值直接平均；其中基底在各批次的 section 数不同，980 键中 35 键与“先批次内平均、再等权平均批次”不同。不能把 section 重复冒充新的独立生物重复。
- 巨噬 `_Normalised` 信号匹配平均原始 ratio ÷同 section 平坦基底平均 ratio。原始 ratio 有非有限/错误缓存，例如 `B4S2!E87:F87` 为字符串 `nan`，`G87` 为 `#VALUE!`；它们保留缺失身份，不填成 0。公式 `F/E` 只读取文本与缓存，不执行。
- 原文统计描述、建模描述对归一化对照及计算顺序的说法不同；数字匹配不能替作者裁决。
- hiMSC 是永生化细胞，3 次独立实验使用不同 passage；第5天 ALP 免疫荧光，不是 ALP 酶活、矿化或骨修复有效性。巨噬原文分别出现第6天与第9天表述，暂缓统一时间标签；IL-10/TNFα MFI 比不是两类细胞计数比。

## 开发者怎样复用

在产品根运行，输出目录必须不存在：

```powershell
.venv/Scripts/python.exe scripts/inspect_chemotopo.py --directory ../../references/auto-research/10-chemotopochip/2026-10-31 --output runs/my-chemotopo-inspection
```

输出 `qualification.json` 包含：固定来源身份、每表标题与缓存状态、980 个组合及 Polymer 对照、35 个纹理的描述符、原始行号、每一步实际单元格、候选分母比较、结构性空位、重复覆盖、均值/SD 重算和未解决问题。坐标需与外层工作簿文件名一起使用；不要将这些大规模数值记录无筛选塞入模型上下文。

实现复用现有 C01 的 ZIP/XML 大小和路径限制，以及归档读取前后的身份检查，不改 C01 评价器；拒绝宏、外链、重复键和错位标识。标准库读取缓存，无新增 Excel 依赖、联网、自动解压落地或训练。缺失原始响应只在显式有限子集上做算术核对，并单独记录原坐标；核对成功不等于缺失值有效。文件尾部重验固定哈希。

## 下一项研究的门槛

下一候选问题为：**在已知化学类别、固定 hiMSC 培养条件下，材料几何能否帮助预测未见纹理的第5天响应？** 目前尚未执行；字段审查已查看响应，因此也不追称这批材料为盲测。

1. 先从原始红色/绿色通道记录、染色与图像管线定义确认哪个信号对应 ALP；明确零细胞 spot、技术重复及平坦对照的处理。若另行构造目标，命名为“本项目按明确规则重建的终点”，保留原汇总冲突，不能称复现作者标签。
2. 按 `Topography` 整组留出全部化学组合与重复。化学类别暂限已知集合；独热编码不支持未见化学结构的泛化声明。独立供者/实验室外验仍未提供。
3. 先冻结少量纯几何特征、化学类别及计分规则；预处理和调参只在训练组内。当前预定的十个几何候选见代码 `GEOMETRY_CANDIDATES`，不是根据响应挑出的最佳集合。243→65 描述符来源和测量定义仍需补核。
4. 比较简单基线、化学单独、几何单独和联合模型；Agent 能提出修订，但不能改评价器、偷看留出反馈调参或把失败研究改写成成功。新的模型成绩与旧 C01 分开登记。
5. 真正值得探索的是：Agent 能否识别来源冲突、阻止无效训练、重建可复算输入，再在固定评价下做有证据的修订；当前已经证明了发现和保留冲突，尚未证明模型增益、成骨机制或自动科学发现。
