# 导出当前研究综合报告

综合报告面向阅读与交接，把同一封存工作台中的实际数值结果、来源状态、管线设置、模型读取与判断、开发助手核对及未解决问题放在一起。既有数值PDF继续保留；新报告帮助读者理解当前证据链，不新增实验或研究结论。

## 导出入口

实际导出已完成。重新导出时使用新目录，需要现有报告依赖`reportlab`、`pypdf`：

| 输出 | 用途 |
|---|---|
| `research-dossier.pdf` | 连贯阅读当前研究问题、实际结果、证据与缺口 |
| `research-dossier.md` | 可检索、可引用的同版文字报告 |
| `research-dossier.json` | 核对结构化事实、记录身份和来源定位 |
| `manifest.json` | 绑定报告文件字节及对应的封存来源身份 |

输入显式指定封存包，不按目录日期选择“最新”，也不改写原研究、收据或工作台。普通克隆不包含ignored `runs/`；需要取得对应包及其清单后再运行。

当前版式只接受完整P02案例、一个数值候选和未确认ALP的当前状态，其他状态会明确拒绝；不是任意领域、任意研究结构的通用报告器。

## 怎么核对报告

先看来源状态和适用范围，再看每项数值的规则、候选和已保存指标。模型原始判断与操作员补充分别标注；通过工具协议不表示回答已科学批准。需要回查时，沿JSON中的快照、行动ID、来源哈希和坐标回到同版工作台或来源文件，不能将不同轮次的同名别名混为一处证据。

报告须保留旧未知请求、未应用回复、未决判断及后续实际读取的区别。保存的CellProfiler配置不等于执行结果；表格缓存、列头或局部算术核对也不自动证明作者完整公式与导出映射。费用状态和预算不能因导出或复制目录重置。

导出新增模型调用0、拟合0，不训练模型权重；不声明新的学术发现、ALP生物资格或独立实验验证。

## 在工作台查看

当前工作台`http://127.0.0.1:18784/#/outputs`已挂载同版报告。顶部“当前研究报告”及成果页PDF下载均指向已生成文件，另可下载Markdown与JSON。`config/workbench-p02.json`中的可选`dossier_directory`绑定原报告；打包只核对来源和文件，不重新生成PDF。更换任何科学输入后，应显式导出新报告并更新配置，不能沿用旧报告作当前结论。
