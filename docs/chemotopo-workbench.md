# P02 只读研究工作台

复用现有五页外壳、悬浮玻璃导航、实色内容卡片和X6无限画布，将已执行的P02轨迹与条件记忆放在同一冻结快照中阅读。总览显示实际调用与记忆数量；研究页提供画布与过程记录；实验页比较固定四规则；知识页按来源、行动、条件观察分类；成果页下载真实JSON和SVG。

从产品根启动：

打开 `http://127.0.0.1:18770/#/overview`。原始记录可预览、完整阅读并返回原分类、滚动位置与焦点；画布布局按案例和快照隔离，只保存于本浏览器。实际运行需对应冻结来源与分析身份，不能改旧研究配置绕过身份核对。

页面使用`/api/p02/research`，下载入口为`/api/p02/research.json`、`/api/p02/memory.json`、`/api/p02/policy-comparison.svg`。没有论文PDF或复现ZIP时不显示这些成果。页面不启动模型，不写入研究或记忆，不接通AgentArts。
