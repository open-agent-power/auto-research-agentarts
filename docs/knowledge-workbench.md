# 知识空间的参考资料库

知识空间保留“项目记录”，另外提供“参考资料库”。前者是研究采用的材料、配方、诊断和条件记忆；后者读取研究工具使用的同一份冻结索引，帮助队员核对资料内容与出处。搜索和阅读不运行资料中的命令，不发模型请求，也不创建研究动作。

## 挂载与阅读

在产品根启动C01工作台时显式传入`--knowledge-index`。下面是操作者本机现有资料的位置示例；克隆仓库不会取得外部文献与运行文件，新环境先按[检索入口](knowledge.md)构建自己的索引。

打开`http://127.0.0.1:8770/#/knowledge?view=library`。搜索可选择平台文档、项目档案、论文页或复用说明；每次最多8段、同文件最多2段。结果采用已有词法检索，不生成答案。卡片的类型图示不是论文插图。

在项目引用的完整阅读页，可进入对应“原摘录”。跳转按citation ID精确读取chunk，核对完整来源记录及行号／页码，不按标题找一个相似页面替代。返回时保留搜索、资料类型与阅读位置。

## 身份与边界

- 索引的数据库SHA、外部manifest与库内manifest须匹配，路径与文件类型也受限制。每次读取保持冻结身份，改变文件后不把另一版本当作原研究资料。
- 同时挂载研究交付时，语料与全部研究引用的完整来源元数据、位置必须精确匹配。只看原文件哈希或PDF页码不够：同一页可能有多个chunk，同一文件重新提取的文本也可能变化。
- 页面还比较绑定的研究原观察身份，防止服务重启时并行请求分别取得研究A与资料库B。项目引用入口仅在研究身份匹配时开放，摘录返回再次核对请求ID及当前引用的完整source／location。
- 页面同时使用语料与数据库身份。原索引的corpus SHA不覆盖提取文本变化，所以缓存和返回值额外核对数据库SHA。
- 原摘录来自已索引快照。此读取入口不重新下载文档、不重新解析PDF，也不重新核验当前参考原文件或官方签名。源文件与提取文本哈希分别保留，不能将数值匹配写成内容真实性、许可或科学有效性认证。
- 论文按页进入索引：当前2453项由1037份平台文档、28份项目档案、1385个论文页及3份复用说明组成；1385页来自27份PDF，不是1385篇论文。

来源可能有版本差异和相互冲突，命中资料后仍须判断适用条件。研究记录、平台真实运行、方法有效性和科学独立验证分别验收。资料库读取不会解除累计5元费用边界或平台暂缓状态，也不把论文全文加入研究复现ZIP。

## 只读接口

| GET路径 | 返回 |
|---|---|
| `/api/c01/knowledge` | 是否挂载、索引统计与身份、研究引用绑定情况 |
| `/api/c01/knowledge/search?q=...&kind=...&limit=8` | 原检索结果及数据库身份；kind可省略 |
| `/api/c01/knowledge/citation/<64hex>` | 精确原摘录、来源、位置与语料／数据库身份 |

查询长度1–512字符，limit为1–8；只接受四种已知kind，不接受重复或未知参数、任意路径或SQL。缺少挂载明确返回不可用；未知引用、非法请求和索引变化分别返回404、400和409。该命名空间POST为405，保留服务已有Host与Origin边界。

运行证据保存在操作者ignored runs中。专项测试和实际全库／浏览器验收分别记录，不将构建成功或小型测试库通过当作完整使用路径通过。

2026-10-31实际使用上述64MB索引完成挂载与四类搜索；10项研究引用全部精确匹配，其中3项为实际动作采用的引用。五个固定查询覆盖四类资料与零命中，返回的15段摘录逐一与精确读取接口比较一致；这不是语义正确率盲测。浏览器实际检查桌面1440×900和手机390×844的全页与分段截图、搜索筛选、键盘阅读返回、研究版本切换及原引用跳转，并注入错误研究身份、DB身份、来源记录和citation ID确认拒绝混用。
