# 当前实现范围

产品提供可恢复的本地研究项目、受限方法选择、来源登记与阅读、知识检索、批次执行和快照报告。工作台包含总览、研究、实验、知识和成果五页，研究页使用 X6 画布。

正式规划见[产品计划](plan.md)，架构见[系统架构](architecture.md)，本地运行见[项目使用说明](project-slice.md)。

## Limitations

方法目录与执行权限由宿主明确限定；通用开放式研究、合法模型提案的完整执行链和跨任务策略收益仍待验证。AgentArts 产品运行时接入继续暂缓。模型、来源与执行额度需按每次任务明确授权，源码分发不包含本机运行账本、模型响应和研究结果。
