# 用配置声明下一轮数值候选

## 一份协议控制什么

示例为[examples/p02-iteration-protocol.json](../examples/p02-iteration-protocol.json)，只允许以下字段：

| 字段 | 约束 |
|---|---|
| schema_version | 固定configured-iteration-protocol-v1 |
| executor_id | 固定p02-interaction-ridge-v1 |
| goal | 不超过2000字符的目标 |
| candidates | 1…4项，每项只含id与alpha；id和alpha分别不重复 |
| alpha | 有限数值，0.01…1000 |
| max_fits | 140的倍数，不超过候选全部执行所需总量 |
| max_requests | 累计原生请求上限，不因恢复重置 |

## 输入封存与恢复

新研究创建时核验原始来源与历史实验一次，捕获已冻结输入；后续读取核对封存输入的哈希，免于反复重建Excel。原目录后来改变，不等于封存输入随之改变，也不能把新文件静默装入旧研究。

冻结输入、协议、代码身份或预算变化都要求新研究。恢复使用原workspace与新收据目录，累计预算来自原协议；不能通过传新协议、换候选或重置计数继续旧研究。来源未知、输入受损或执行结果不明时停止，不自动重跑。
