# 页面、资料与阅读设计

R8按已确认的五页结构实现。当前仍读取冻结的既有研究；页面重组可选的独立本地脚本演示提供单步实验；不接通真实模型、条件记忆写入或云端服务。能力边界见[架构](../architecture.md)，统一材质见[DESIGN](../../DESIGN.md)。

## 页面与共同外壳

```text
┌─────────────────────────────────────────────────────────────┐
│  悬浮玻璃侧栏       悬浮玻璃项目栏：当前页面 / 项目 / 导出      │
│ ┌──────────┐   ┌───────────────────────────────────────────┐ │
│ │ 项目总览 │   │ 总览：目标、进展、重点结果、下一步           │ │
│ │ 研究推进 │   │ 推进：流程画布 / 过程记录 / 后续问题         │ │
│ │ 实验中心 │   │ 实验：表格、曲线、采用与未晋升详情           │ │
│ │ 知识空间 │   │ 知识：分类图文卡片 / 专用关系画布            │ │
│ │ 成果复现 │   │ 成果：论文全文、目录、图表、复现材料         │ │
│ └──────────┘   └───────────────────────────────────────────┘ │
│                      每次只显示当前页面                      │
└─────────────────────────────────────────────────────────────┘
```

总览是默认入口。五个页面使用各自的主内容结构，不在同一长页堆全部对象与全文。普通页面采用雾色背景；画布的点阵、缩放工具和布局控件只在画布视图出现。清晰的页面标题、导航选中态和可回退地址共同表达当前位置。

## 资料分类和卡片

知识资料由现有来源、数据描述和研究判断映射，原对象ID、出处和状态不变。页面上的分类不成为新的研究事实。

| 分类 | 现有内容如何进入 | 缺失时 |
|---|---|---|
| 文献与证据 | 原始论文来源、带引用的研究判断 | 显示真实数量和空状态 |
| 数据集 | 明确的数据来源及现有数据描述 | 不编造其他领域数据 |
| 方法与工具 | 现有方法文档与对应使用范围 | 不把已调研工具写成已接入 |
| 研究记忆 | 须有独立的条件、来源及复核记录 | 当前为空，不将观察当成熟记忆 |

主题标签是可组合的辅助筛选：多个主题任一匹配，再与资料类型同时满足。医疗、材料和软件工程允许跨领域标记，但每个标记必须能从内容判断；当前没有医疗资料时可以筛到零条。后续更丰富的资料应扩展明确元数据，不依文件名或卡片图片推定机制联系。

卡片显示预览图、类型、标题、简述、来源编号与可核对的状态。年份或版本缺失就不填写。图片只来自允许的本地图表；无原图时使用标注“类型图示”的本地设计，不冒充论文首页、显微照片或实验结果。

```text
[类型/主题筛选]      [卡片浏览 | 关系画布]
 ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
 │ 真实图或    │  │ 真实图或    │  │ 真实图或    │
 │ 类型图示    │  │ 类型图示    │  │ 类型图示    │
 │ 类型与出处  │  │ 类型与出处  │  │ 类型与出处  │
 │ 标题、简述  │  │ 标题、简述  │  │ 标题、简述  │
 └──────┬──────┘  └─────────────┘  └─────────────┘
        ↓ 快速预览 → 完整阅读 → 返回原筛选与位置
```

## 阅读与预览

预览用于快速判断相关性，提供摘要、原始来源、证据引用和完整阅读入口。桌面抽屉外壳使用玻璃、内部正文使用白色。长文进入独立阅读页，以足够宽的正文、章节目录和关联入口呈现；成果页也直接提供论文全文。浏览器后退及页面返回都应恢复原页面与上下文，不把用户送回总览。

资料原文未被保存到当前项目时，只能阅读本地已有摘记和元数据，并提供原始链接，不能称为本地全文。原论文下载、离线参考库索引和产品资料管理仍有独立接入工作。

## 研究流程与关系画布

研究推进默认展示流程画布，可切到过程记录和待处理问题；知识空间也可查看筛选后的关联记录。画布复用X6相机、分组与节点。默认展示“问题与依据 → 提案与实验 → 判断与下一步”，节点使用真实结果图或标注类型图示；用户可进一步展开全景；页面导航与画布操作各自独立。现有引用可显示为“原记录引用”，不能因为卡片接近、连线或分组就推断支持、反驳或因果。

已有对象的映射保持不变：研究问题→project；来源→sources；实验与提案→trials；判断→claims；论文→report；后续问题→next_questions。独立假设、经过核对的条件记忆尚未建模，不为画卡片新增假科学对象。

新画布布局按项目ID、快照与视图范围隔离，旧版本布局保留但不自动套用。布局格式仍为`schema_version`、`project_id`、`snapshot_sha256`、`positions`、`viewport`。只接受已知对象和有限坐标。保存失败、损坏或不适用时，阅读、问题保存和下载仍可使用。JSON Canvas交换格式、任意自由分组、撤销与多人同步均未在本轮实现。

## 真实状态与验收

| 状态 | 页面行为 |
|---|---|
| 加载/读取失败 | 说明正在读取证据或显示重试；没有假研究进度 |
| 分类为空 | 显示条件与空状态，可清除筛选 |
| 条件记忆为空 | 明确尚未有复核记忆，不填充样例假结果 |
| 后续问题保存 | 成功显示待执行；失败保留输入 |
| 未终测 | 明确未执行，不以最低验证误差代替测试成绩 |
| 未晋升候选 | 保留实际指标、原提案与采用理由 |
| 接入暂缓 | 不开放调用、执行或付费操作 |
| 无模糊/提高对比 | 实色功能面板，结构和操作不变 |
| 减少动画 | 关闭非必要过渡，保留焦点和即时反馈 |

验收使用真实三次既有实验，核对五页布局、资料分类、预览→阅读→返回、过程与实验详情、全文图表、问题保存与下载、画布拖动和独立布局。1440×900与390×844均实际截图；长文另外滚动2—3处检查。人工视觉认可与工程检查分别记录。
