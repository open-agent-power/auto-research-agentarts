# 空间研究工作台

状态：用户选择的设计方向；尚未实现。实现前先读[架构](../architecture.md)，避免把空间布局当研究执行引擎。

## 首要路径与信息层次

打开研究项目 → 看清研究问题与未决判断 → 在“依据—假设—实验—结论”间定位 → 侧栏查看原记录 → 明确决定下一行动或导出成果。

```text
┌─────────────────────────────────────────────────────────────┐
│         [项目名称 / 证据版本 / 预算与执行状态]       [导出]  │
│ ┌─────────┐                              ┌────────────────┐ │
│ │ 项目导航│   · · · 点阵研究画布 · · ·    │ 选中对象详情   │ │
│ │ 问题与组│                              │ 原文/方法/数据 │ │
│ │ 搜索定位│  [来源组] ── [假设组]        │ 指标与引用     │ │
│ │ 阅读模式│                 │            │                │ │
│ └─────────┘       [实验与负结果组]        │ 实色阅读内容   │ │
│                     │                    └────────────────┘ │
│                [判断与后续问题组]                           │
│                [选择 / 定位 / 缩放 / 适应全图]               │
└─────────────────────────────────────────────────────────────┘
```

侧栏、工具条、Dock与抽屉外壳是悬浮功能层；论文和对象详情是内容层。右侧抽屉是全文阅读主位置，画布卡片只放标题、摘要、状态及少量关键值。关闭抽屉恢复原画布位置，不丢选择。

## 研究对象如何进入画布

| 对象 | 卡片显示 | 详情读取什么 | 当前可映射性 |
|---|---|---|---|
| 研究问题 | 问题、研究范围 | 项目目标、数据与评价约束 | 现有project字段 |
| 来源 | 标题、来源ID、使用范围 | 官方链接、版本、许可与证据摘记 | 现有sources |
| 假设 | 可检验主张、预期变化 | 对应提案及所引用试验 | 当前嵌在trial.proposal；独立假设对象待设计 |
| 实验 | 配方、验证指标、采用/拒绝 | 实际记录、父试验、工件哈希 | 现有trials |
| 判断/结论 | 主张、依据、局限 | claims与证据引用 | 现有claims；不推定经同行复核 |
| 后续问题 | 问题与待执行状态 | 人工记录、创建时间 | 现有next_questions |
| 条件记忆 | 结论和适用条件摘要 | 复核过程与来源 | 尚未实现，不能以假数据展示为已可用 |
| 论文成果 | 标题、证据版本、导出入口 | 正文、图表、完整引用 | 现有report/exports |

原始对象ID贯穿画布、抽屉、列表与报告。暂未有独立对象的内容只做带来源路径的投影，不能为了画卡片悄悄更改领域模型。

**视觉连线与科学关系分开。**已有引用可以显示“引用此试验”；人工自由连线默认只是布局标注。要形成“支持/反驳”主张，需要独立关系记录、依据和确认过程，不能由卡片接近、分组颜色或连线自动推断。

## 材质、文字与色彩

具体值以[tokens.css](tokens.css)为准。该文件是设计输入，当前运行页未加载。

- 画布：雾灰底、24px低对比点阵；点阵跟随视口变换，低缩放时降低密度。
- 功能层：白色约78%不透明、20px背景模糊、细外边框与内高光。正文小字必须稳定可读；实际背景下不足时提高不透明度。
- 内容层：白色或近白实色，长文行长约60—80个中文字符；不让点阵、线条或彩色分组透到正文下。
- 分组：鼠尾草绿用于依据，砂色用于假设/待检验内容，淡紫用于综合判断；语义仍由文字和图标表达，不靠颜色判定成功。
- 状态：采用、拒绝、失败、待执行与证据不足分开。拒绝候选不是系统失败；完成执行不等于科学主张成立。
- 字体：中文系统无衬线，正文14—16px、卡片标题15—16px、项目标题20—24px；数值用等宽数字。大标题不抢占画布。
- 图层：分组底框 < 连线 < 卡片 < 选中态 < 悬浮控制 < 抽屉 < 对话框。不会被白板缩放的控件置于画布变换层之外。

## 最小交互范围

| 交互 | 预期行为 | 不应产生的副作用 |
|---|---|---|
| 平移/缩放 | 空白拖动或Space拖动，工具按钮适应全图、缩放和复位 | 不修改研究记录 |
| 选择/定位 | 单击选卡，双击或Enter开详情；搜索定位同时可见卡片与分组 | 不自动启动研究 |
| 移动/分组 | 移动卡片和低饱和分组，保存独立布局；可撤销 | 不改实验父关系与证据引用 |
| 查看详情 | 抽屉实色正文，长文内部滚动，关闭返回原焦点 | 不隐藏原始数据及局限 |
| 后续问题 | 显式保存并反馈成功/失败；保持待执行 | 不显示虚构Agent回复 |
| 研究执行 | 后续接通控制器后提供独立明确动作，展示范围与预算 | 不由拖动、连线、页面打开触发 |
| 论文阅读 | 可切到线性阅读模式，保留同一对象与引用身份 | 不再维护一套独立事实 |

首轮不做自由绘画、多人实时协同或任意插件系统；这些不是连续研究成立的前置条件。

## 视口、布局和状态

大屏默认保留左导航与中央画布，右抽屉按需打开；全图适配计算须扣除悬浮面板占用，选中节点不能被抽屉盖住。窄屏使用单列对象列表与全屏详情，白板作为可选浏览视图。列表可做完整的定位、阅读和导出路径。

布局拟采用独立版本化文档：`schema_version`、`project_id`、`snapshot_sha256`、`viewport`、`nodes`、`edges`。节点布局只存对象引用、坐标、大小、折叠与分组；研究正文从后端投影读取。暂未建立这个存储或API。

JSON Canvas可作为导入导出格式，但它没有定义科研主张、执行状态或控制权限。须通过适配器保留`text/file/link/group`等格式语义，并另存研究对象映射；禁止将外部file节点直接当作服务器可读取的任意路径。

| 页面状态 | 界面表现 |
|---|---|
| 加载 | 稳定的HUD轮廓与说明；不伪造正在研究的Agent |
| 空项目 | 引导选择已有证据或准备研究，不填充虚构成果卡片 |
| 证据失效 | 保留定位，说明读取失败；禁用依赖该证据的动作 |
| 保存中/失败 | 明确反馈，失败不丢输入；布局保存与问题保存分开 |
| 接入暂缓 | 状态可见；无法执行的操作不给假成功 |
| 无背景模糊/减少透明度 | 实色HUD与明显边框，结构不变 |
| 减少动画 | 关闭镜头飞行与Dock放大；按钮与键盘仍可操作 |

## 实现验收

用真实快照验证完整路径，包含3条既有候选、拒绝记录、长标题、长引用和未终测状态。实际检查1440×900与390×844的全页及分段截图；拖动、缩放、抽屉、键盘、列表回退及重启布局恢复分别走通。视觉效果与数据持久化分别给证据，不用静态截图代替交互验收。
