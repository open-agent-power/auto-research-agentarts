# P02：区分数值事实与研究判断

## 适用任务与两条比较轴

| 类型 | 具体比较 | 事实与权限边界 |
|---|---|---|
| processing_rules | 同一原始来源下的零处理及重复聚合规则 | 不是几何特征增量，不推断哪种规则科学正确 |
| model_inputs | 同一规则下化学Ridge与化学＋几何Ridge | 主指标MAE与次项Spearman分开，不跨规则挑赢家 |

宿主从已保存留出预测复算指标，生成带类型、比较轴与ID的数值事实：四规则中增加10几何字段后MAE均更差，Spearman均更高。这是宿主算术核验，不是模型自主发现；原目标仍依赖已测平坦对照，ALP门槛保持关闭。

## 模型负责什么

预测焦点提供相关的来源检查、项目检查、预测读取、`review_prediction`、记忆和暂停／停止。它不提供无关的`compare_policies`、通用评议或资格查询工具；关闭的资格仍在上下文中显示，不能靠换焦点开放。

`review_prediction`须引用当前预测行动和真实fact IDs，包含主MAE事实，记录`continue`、`revise`或`pause`决定以及`hypothesis`、`next_check`。数值事实与模型判断分别保存：强制引用不保证模型文字真实，假设和下一步仍是未经验证的解释，也不授权执行后续实验。模型自主选择工具顺序，不强制remember或recall。
