# 配方与RSI板块队友任务

更新于2026-11-05。当前分工与实施入口统一到[配方与RSI开发任务书](recipe-research/team-module-handoff.md)和[最小接口约定](recipe-research/team-module-interface.md)。

队友负责通用配方、方法知识的读取与候选关联，以及反馈驱动的RSI改进外环。主开发负责研究计划、模型传输、真实工具、前端和平台整合。

先选一个可替换的实例完成问题、计划、工具、反馈和修订的全流程验收，复用已有已完成节点。随后由实际轨迹驱动下一项配方、策略或实现改进，每轮提出候选、执行必要验证、保留或回退，再继续推进。

PR1交配方与改进对象、读取与关联，建议11月8日前。PR2交外环、版本与采用、连续推进及接续，建议11月12日前。11月14日前联合取得一次真实改进及后续轮次利用前轮反馈的记录。实例材料的后续调查回到对应项目处理。

已有配方PR和控制器接线继续复用，具体历史范围查[接入记录](recipe-research/integration.md)。本月总体安排见[11月提交计划](research/submission-plan-20261130.md)。

交付中保留实际命令、结果、当前有效版本、未决问题和下一步。文件所有权、源码基线、Git与PR方式及检查范围在任务书中说明，任务包附完整源码快照、构造context和待实现接口模板。
