# 数值关联与分组方向核对

`data.numeric-association`在已完成的表格质量检查后，对声明的数值列与目标列计算样本内描述性Pearson关联，同时按声明分组保留结果。它回答有限的数值问题，不训练模型。

本文实例的问题是：**BMI与原`progression_target`字段在本样本中的关联方向，是否在原`sex`编码的各组中一致？**输入在计算前即把`bmi`指定为关注变量。

## 字段声明与来源

继续使用[表格输入声明](tabular-quality.md)，字段必须与已捕获CSV精确一致：

| 声明 | 本例及含义 |
|---|---|
| `target_column` | `progression_target`，由原loader的target按原行序追加并重命名；同时须在`numeric_columns`中 |
| `numeric_columns` | `["bmi", "progression_target"]`；只分析预先指定的BMI与target配对，原CSV其他列保留 |
| `group_columns` | `["sex"]`，使用原编码；不自行映射为男或女 |
| `key_columns`、`sample_unit` | 保留原声明；行数和组计数不证明独立受试者数 |
| `target_unit`、`missing_tokens` | 保留原目标量尺未确认说明和缺失标记；零值不自动作为缺失 |

官方说明给出442条记录、10个基线特征，`bmi`为BMI，target为基线一年后的定量疾病进展指标；该说明没有给出`sex`编码映射或target的具体量尺。[scikit-learn数据集说明](https://scikit-learn.org/stable/datasets/toy_dataset.html#diabetes-dataset)

默认`load_diabetes(scaled=True)`对特征进行均值中心化，并除以标准差与样本量平方根的乘积；`scaled=False`返回原特征。**本例已捕获的是`scaled=False`投影，不是默认标准化版。**使用其他捕获版本时保留其原值、版本及缩放声明，不擅自还原单位或改成另一版本。[load_diabetes API](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_diabetes.html)

本例复用已捕获的`diabetes-raw.csv`原字节：442行、11列、25689 bytes，SHA256为`f59565c20159695cbb80b9c767020e1e126cb244f767befba856fc0e01cadaf1`。原spec记录本机scikit-learn 1.9.1、`scaled=False`、保留loader行序及原target重命名；本轮仅把分析数值声明限定为上述两列。来源与许可声明继续随输入保留，不能把本机导出CSV称作作者原始CSV。早先质量检查和已读取源码的范围见[A63记录](host-model-selection.md#a63-真实子代理计划修订与后轮接续)。

## 从工作台执行

1. 在“项目总览”按[工作台入口](local-workbench.md#从问题推进一次)导入真实CSV与spec，核对声明后创建项目；创建只封存输入。本例为单独声明的描述性问题，明确本地上限2次，分别用于质量检查和数值关联，旧A63/A64项目与额度保持原记录。重开沿本例原项目与累计账本继续。
2. 在“研究推进”保存本轮问题、依据和停止条件。先完成质量检查，阅读实际反馈；质量检查完成不代表目标量尺、编码和独立性已批准。
3. 在“开展下一步”选择当前context中的`data.numeric-association`候选，写明只核对样本内BMI与target的整体及原编码分组关联，再“明确执行所选候选一次”。没有候选、前序失败或额度不足时，保留实际阻塞，不换目录重置额度。
4. 到“实验中心”阅读完成行动、反馈及完整原记录，核对整体与分组的成对记录数、排除数、Pearson r或不可计算原因。阅读结果不继续执行。
5. 到“成果与复现”生成当前快照报告，取得匹配的报告与重现输入。报告必须包含本次行动；旧报告不能替代新结果。

本方法消耗一次既有本地工具额度，模型调用和拟合均为0。它不因来源为公开数据而获得额外执行授权；来源读取、宿主模型和历史费用仍沿各自原账本处理。

## 读数口径与完成标准

结果schema为`numeric-association-v1`。每个数值列与target单独成对处理：只有两者均为有限有效值的记录进入该对计算；空值、声明缺失、无效数值与非有限值按保存口径排除。某一列缺失不自动删除其他列的有效配对；每条被排除记录在该配对中只计一次。

| 原记录 | 阅读方式 |
|---|---|
| `summary` | 全部行数、分组完整/不完整行数及完整组数；不是独立患者数 |
| `overall` | 全体记录的配对结果，含`predictor/n/excluded/pearson_r/reason`；`n`为有效配对数，`excluded`为排除数 |
| `groups` | 每组的`rows`、`group_id`和同口径`associations`；用`first_coordinate`回到原CSV核对原编码，不自行命名男/女 |
| `incomplete_group` | 分组字段不完整记录的行数及配对结果，单列保留，不并入已知组 |

整体配对的`n + excluded`等于全部行数，各组则等于本组`rows`。分组首条定位的`logical_record`从1起且不含表头，`physical_line_end`包含表头及CSV换行；其余排除记录按捕获原CSV与声明复核，摘要不提供完整逐行排除清单。

有效配对不足时`reason=insufficient_pairs`；常量原因分别为`constant_target/constant_predictor/constant_both`，相应r为`null`。可计算时`reason=null`；r不可计算不能写成0或“无关联”。零相关没有正负方向。只有整体及各原编码组的`bmi`配对均可计算时，才按实际r符号描述方向是否一致；不同符号或不可计算也都是应保留的结果。

完成要求是：原控制器行动为`completed`，前序质量行动与输入身份可追溯，整体及各组的有效数、排除数与r/原因均有原记录，当前报告能定位该行动。数值方向的一致不等于组间效应相同，也不替代科学解释。

## Limitations

本方法只描述已捕获样本中的线性关联，不给出因果、临床决策、预测性能、显著性或外推结论。极端值、非线性、成对排除及组间构成可能影响结果，未验证样本独立性时不能按独立患者推断。目标具体量尺、编码定义、独立性与原数据使用条件仍按来源证据核对；机械检查无标记不表示这些问题已解决。单个公开数据实例也不证明自适应研究收益或真实研究者采用。
