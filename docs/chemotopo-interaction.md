# P02：化学与几何交互的固定诊断

## 唯一新增方法

保留化学独热与原10几何主效应，再加入全部“化学独热×标准化几何”乘积项；固定Ridge(alpha=1, solver=svd)，不调参、不筛交互、不改目标。每折独热类别和几何StandardScaler只在训练纹理拟合，再把同一尺度用于测试纹理及交互项。Topography编号只作分组键，不作输入。

## 判定方式

主指标仍为每规则合并留出MAE。完整比较化学基线、加性几何、交互方法，不跨规则选择赢家。另保存每规则35个配对折的MAE差值（交互减加性，负值表示误差下降），以及次项Spearman；不因排序指标提高而换主指标。

四规则MAE均改善才支持“该固定交互表达具有增量预测价值”，不证明化学—几何生物机制。全部不改善或变差，则本次不支持该固定recipe，不能推出所有交互或非线性方法均无价值。混合结果逐规则保留，不挑有利规则宣布整体成功；配对折也不冒充独立生物重复作显著性结论。
