# G2-L saved-evidence coordination comparison (frozen before execution)

This compares deterministic **trusted local analysis tasks**, not LLM agent
quality or autonomous research. Inputs are the finished, exhausted Concrete G1-L
case. No fitting, API/model sends, native research commands, historical database
writes, arbitrary-code task loading or new research allowances are permitted.
G0 resource isolation and G4 restrictions remain unchanged.

## Fixed work and comparison

Each arm receives the same four tasks and exact source/hash/locator triples:

1. Recompute baseline saved-OOF MAE, reference MAE, negative count and coverage.
2. Recompute candidate saved-OOF equivalents from its actual saved artifact.
3. After tasks 1 and 2 are host-reconciled, compare complete paired identities,
   worsened rows, groups with any worsened row, groups with worsened mean absolute
   error, and negative predictions; keep these distinct adverse quantities.
4. Audit frozen final project allowance and unknown-cost fields, without opening
   the historical SQLite database or consuming its remaining tool allowance.

All arithmetic runs from copied frozen input bytes. The whole original case
tree receives before/after file-SHA manifests. Its files must remain identical.
ProjectRef uses the real project ID, source snapshot identity and exact final
state snapshot file SHA. Each task has one coordination attempt, zero native
tool/fit/model authority, and a 30s host timeout declaration. A comparison arm
has four coordination attempts; these are not new scientific compute grants.

Arms: single, static (up to two trusted analysis threads), dynamic (same maximum,
positive-value ready task selected by frozen host value/effort). All four tasks
have positive values and every arm must complete exactly the same work. Values
are host estimates, not learned benefits. No task is dropped to manufacture speed.
One common unmeasured warmup performs each analysis once; thereafter three
repetitions rotate arm order: single/static/dynamic, static/dynamic/single,
dynamic/single/static. No sleeps, artificial load, or repeated inner kernels.

The host claims tasks, runs only the four fixed analysis functions, submits
strict AgentResult data and reconciles the exact attempt/result SHA. Threads
never write the native case; the main host owns SQLite mutations. Trace retains
task/agent/attempt, input and result identities, action references, read-only
analysis duration, orchestration duration and total arm wall/CPU time. The
new task ledger keeps exact requests/results/reconciliation receipts.

## Decision and limitations

Hard requirements: identical task set, identical per-task analysis output hashes
across every arm, accepted source triples, all DAG tasks completed, no unknown
claims, four coordination attempts, zero native fits/model/API sends, and unchanged
original case bytes. Mismatches stop acceptance and remain visible in output.

Report all nine timings and arm medians, order, warmup and overhead. Three
repetitions on small cached Python/JSON work cannot establish statistical or
research-quality benefit; shared-process threads also face the GIL. Retain
single as default unless a later representative workload demonstrates meaningful
quality, coverage, efficiency or cost improvement without evidence/state loss.
Passing this local coordination check does not pass the original full G2 Gate.
