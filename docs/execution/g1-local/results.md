# Concrete 可信本地研究切片：两轮结果

本轮已完成经用户批准的可信本地研究、观察驱动的计划修订、原生报告及独立技术接续。**这不使原G0隔离门通过，也不证明自主模型runtime、跨课题收益或RSI。** 机器摘要见[验收记录](acceptance.json)，独立证据见[审查](independent-review.md)和[界面验收](ui-verification.md)。

## 问题与固定协议

使用UCI Concrete的全部1030行、8原输入和MPa抗压强度目标。官方来源、CC BY4.0、作者I-Cheng Yeh、DOI、9270原数值token、行顺序和派生映射已[独立核验](data-preflight.md)。七材料Decimal精确相等定义427个配合比签名；246组单例，181组多龄期。签名不等于已验证实验批次。

保留原九数值中的25条额外完整重复。上传表加入唯一source_row后，原生11列完整行重复为0；这个0不表示原始数值记录没有重复。

原八输入采用固定五折GroupKFold、训练折StandardScaler及Ridge alpha1，参考为对应训练折目标均值。每行恰好评价一次，同一签名不跨训练与评价。第二轮只将age映射为ln(1+age)，其余输入、全部行、组、折和参考保持，不删行、调参、裁剪或追加候选。两轮共10次Scaler和10次Ridge拟合。

## 观察怎样改变计划

计划v1在拟合前保存：核对质量和来源、运行基线、根据真实保存误差决定下一步。

第一轮实际MAE为8.383388MPa，优于训练折均值参考，但85/427组较参考更差。完整保存诊断及其派生龄期核对显示：3天134行均高估，平均误差+13.522130MPa；56天为−8.810559MPa；360/365天再次明显高估。组内3→7天64组的平均观测变化9.076406MPa，预测变化仅0.456006MPa；180→360天6组的观测变化1.423333MPa，预测变化20.446797MPa。

宿主Agent据这些**本次已保存行动ID、结果SHA和完整诊断**形成计划v2，检验预声明的唯一log1p表达。竞争解释保留：未记录试件/批次/实验室条件、覆盖稀疏、重复和其他非线性。观察不确立龄期因果或物理定律。新resource-v2替换了历史示例中的旧研究引用，只引用本次真实工件；没有将历史成绩写成新观察。

## 验证、预算和接续

冻结评价器只读SQLite和原始CSV，用NumPy重建训练折统计、保存系数预测、MAE及全部父子行/组/折对应；3252项检查通过，评价期间拟合函数被禁止。基线阶段仅有一个拟合行动时，完整验收器保留其exit1未完成结果；没有修改评价器让它提前通过。

独立成员重新打开原manager，禁止拟合、adapter执行、来源提取、模型、网络、CLI及新报告渲染，成功重放29次原请求；11项检查通过，原96个文件字节、完整状态及累计预算不变。另有15项流程/来源检查，确认实际反馈先于计划v2。完整case复制到新路径后，独立验算3252项及29次原请求重放/18项检查再次通过，恢复副本101个文件字节与预算不变；重放时禁止访问原case，仅对同内容source bundle作内存存储路径映射。该结果是同环境迁移，不是G6干净机器安装验证。

原生工作台五页及390px代表页实际浏览，四份报告下载均与manifest/磁盘SHA一致。PDF39页，已检查文本并查看首页末页；没有全PDF视觉或真人满意度结论。保存算术图展示完整OOF及14个龄期的误差和样本数，图形不新增fit或工具行动。

最终计划v3与原控制器wait收口：本地工具5/6，estimator尝试20/20（10Scaler+10Ridge），来源提取1/1，产品模型/API发送0，没有unknown或未决fit预留。一次监督器用错宿主解释器的元数据预检在worker启动前失败，原失败保留，改用冻结venv后未改变研究环境。三研究阶段的实际监督回执均退出0，观察峰值RSS低于187MB；该监督不是cgroup隔离。
