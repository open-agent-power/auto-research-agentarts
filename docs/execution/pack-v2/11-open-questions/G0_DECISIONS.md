# G0 Decisions to Close

1. 首个真实表格研究课题：数据集、来源、许可、字段语义、研究目标、领域复核人。
2. 基线方法：最简单且合理的固定分析/研究流程。
3. 评价器：哪些指标自动判定，哪些结论需要领域专家复核。
4. 模型和 Runtime：当前可用模型、CLI/API 权限、预算、非交互运行。
5. Worker：Docker 限制、网络、文件、持久化、Artifact 回传。
6. 跨课题改进数据：多少独立课题/任务能支撑初步迁移评价。
7. RSI 晋级：自动晋级范围与必须人工批准的边界。
8. 本轮范围：一个完整真实表格研究垂直切片是硬目标；RAG/算法按核心闭环完成度分阶段。
9. 旧 runs 和本机计划：如何安全交接到云端，不重置预算和身份。
10. 上游引入：逐个 PoC，不允许一次性集成多个大框架。
