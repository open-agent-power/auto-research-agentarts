# Artificial time-bound quality primary

This separate Python opt-in accepts only the fixed S134 artificial 28-hour
packet after the original S084 quality and S135 artificial time registrations.
It uses the quality registration's original future Controller ID. A first
explicit request may dispatch at most one local quality tool. It does not
authorize a model, fit, evidence read, real UCI input or other research.

The manager authenticates the original manager intents, receipts and Project
claims, current plan and budget. A versioned parent binds those original
registrations, the report directory and report identity. Project-side parent
and child claims are separate transactions; the child is accepted only once.
The source and report are checked before parent and child acceptance and
again after child acceptance before the adapter runs. If the latter check
fails, the accepted running child and its reserved budget remain for
inspection. They are not evidence of an unaccepted action.

The resume-only entry authenticates a complete original parent, child, claims,
source and result before it can return or finish the original manager receipt.
Missing, failed or nonterminal records stop without redispatch. A completed
quality action can have a legitimate unknown quality condition; it stays
unknown. A damaged original is not converted into a valid unknown condition.

The public quality reader may return unknown early when a parent has not
completed. That early result does not authenticate the time originals or prove
that no action ran. For a completed v2 parent, the reader performs observed
before/after source, Project and claim checks; it does not hold a writer and
does not claim writer isolation. Write paths hold the Project writer. These
cooperative checks do not protect against processes that ignore the locks or
coordinate changes to all local evidence; hashes are not signatures.

The S132 four-row entry remains separately restricted to its original packet.
Older generic paths are not made into a global time gate: an old entry may
compete before the new parent is created, and an existing foreign action is
never adopted. Producer source changes require a new pinned synthetic Project
and new S084/S135 registrations. Existing Projects are not migrated. The
artificial clock does not verify any real UCI station, time zone or licence.
