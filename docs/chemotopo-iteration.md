# P02：模型选择下一次数值实验

## 执行与恢复边界

拟合前先持久预留行动与预算，再执行固定任务。完整工件已经落盘而行动未提交时，恢复核对完整清单并提交同一行动，不重新拟合；仅有部分输出或执行情况未知时保持阻断，不把“重跑一次”当安全恢复。未知模型发送也不自动重发。

## 创建与恢复

从产品根创建独立研究；来源、两个历史附件与目标由操作者提供，模型不能改路径或预算：

`--max-new-requests 0`可只建研究／写study.json，不调用模型。恢复使用同一workspace与新output，来源、历史目录和目标可省略，显式传入须与冻结值相同；预算不清零。候选须引用`p02-r54`、`p02-r59`及已有的最新行动。完整工件在研究目录的`artifacts/<request_id的SHA256>/`中保存result.json与complete.json，未知部分输出阻断而不自动重跑。
