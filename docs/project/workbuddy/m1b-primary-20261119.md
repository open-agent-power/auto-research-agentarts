## 6. 这轮真正的发现

1. **dev/validation 分歧本身就是结论。** dev（8 题）上候选臂全面领先（Δmrr +0.1875、Δr@5 +0.125、
   r@1 0.625→0.875），validation（24 题）上全面收敛到 0 附近。用 8 道题给两个词法排序器排名，
   得到的是噪声。以后任何结论都不能只报 dev。
2. **M1 的「tf-idf 在前 5 位更好」不成立于扩池后。** 它在 85 篇池子里成立，是因为池子小到
   任何词法检索都能把正例捞进前 20，剩下的差别纯粹是排序抖动。
3. **候选臂的增益方向不稳定**：`q-val-05` 的 +1.0 来自 BM25 退化，`q-val-13` 的 −1.0 来自 tf-idf 退化。
   两边都在被干扰池影响，方向不能预测。
