## 1. 为什么要有这一轮

M1 的主终点 `recall@20` 在 32 题上两臂全为 1.0。原因是结构性的：85 篇语料 + `top_k=20`，前 20 位
覆盖 23.5% 的语料，每题又只有一个正例。终点没有方差，问题「召回提升是否伴随 MRR 下降」在 M1 包上
**无法回答**——这不是「两臂等价」。

M1b 只改一个变量：**干扰池**。语料从 11 个 Part 的 85 篇扩到同一份冻结卷的全部 940 篇
（85 篇正例池 + 855 篇干扰），`top_k=20` 的覆盖率降到 2.1%。题目、qrels、正例正文、协议常量、
打分器代码全部不变。

## 3. 终点与判定（**跑之前写死**）

- **主终点**：validation `recall@20` 的配对均值差（tf-idf − BM25）。
- **共同主终点**：validation `mrr@10` 的配对均值差。
- 次要：`recall@5`、`recall@10`、`ndcg@10`；以及每题的「正例落在第几位」分布。

判定规则（互斥，先命中先算）：

| 编号 | 条件 | 结论 |
| --- | --- | --- |
| D1 | Δrecall@20 > 0 且 Δmrr@10 < 0 | 「召回提升伴随排名下降」在扩池后**复现** |
| D2 | Δrecall@20 ≥ 0 且 Δmrr@10 ≥ 0 | 本包**未观察到**该权衡（不等于不存在） |
| D3 | 两指标全部逐题差值 ≤ 1e-12 | 本包上两臂不可区分（报告正例 rank 分布，说明是池子的问题） |
| D4 | 其他（如 Δrecall@20 < 0） | 如实报告方向，逐题列出，不解释成机制 |

补充规则：

- **不做显著性之外的外推**。n=24 的配对样本只报均值、胜/平/负；若不一致对数 ≥ 6，另报二项精确
  检验双侧 p（零假设 p=0.5），**仅作描述**，不作确认性推断。
- **一题都不许只进均值**。凡两臂指标有任何一项不同的题，逐题列出 id、两臂值与差值。
- **不许调参**。`k1`/`b`/tokenizer/`top_k`/指标定义在任何结果出现后都不得改动；想改须新卡。

## 5. 已知限制（写进结论，不许省略）

1. **855 篇干扰没有相关性判定**。评价时按「未标注 = 不相关」处理，两臂同等待遇。若某篇干扰其实
   能回答某题，两臂都会被少算一次召回——绝对召回是**下界**；配对差值只在「两臂拿到未标注命中的
   概率相当」这一**未验证**假设下可解释。
2. **干扰与正例的抽取规则不同**：干扰多收标题/表格/注释，丢掉权力依据行与上标。这只改变难度，
   不改变任何标签。
3. **权利筛查对干扰是机械规则**（版权/许可转载/标准号/并入引用一律排除），不是逐篇法律审查；
   本轮因此排除 15 篇（另排除 27 篇 [Reserved]/无正文、9 篇重复条款号、1 篇超长，共 52 篇）。
   正例 85 篇沿用 M0 的逐条审查。
4. **同一份源换了两个语料规模**，两次结果不可当成「两次独立实验」；M1b 是 M1 的**同一课题、
   不同干扰池**，属于对同一假设的第二次检验，不是复现实验。
5. 冷上下文复核不等于第三方独立评审；对外只能写「冷上下文复核通过」。
