# 自主研究基线：外部方法调研与项目适配（2026-11-15）

本调研回答三件事：如何区分“系统能运行”与“解决了真实研究问题”；如何判断历史经验被实际使用、是否改变结果；如何把复现、成本和失败纳入验收。参考均为公开一手论文/仓库的只读材料，没有安装项目、下载任务数据、调用研究模型或付费 API，也没有宣称复现其结果。引用是方法依据，不是本项目效果证据。已有本地 [ScienceAgentBench 条目](../recipe-research/sources.csv) 和[产品概念证据](../research/product-concept-evidence.md)已覆盖部分材料，此处只补项目当前缺口。

## 1. 分开验证执行、科学结果和成本

[ScienceAgentBench 论文 v3](https://arxiv.org/html/2410.05080v3) §2.2–2.3、附录 D/G：作者从44篇论文构建102项数据驱动科学任务、由领域专家核验；把程序、实际运行结果、任务成功标准和成本分开考察。作者评估的是特定工作流任务，不等于证明端到端自主科研。其 [官方仓库固定版本 c26e151](https://github.com/OSU-NLP-Group/ScienceAgentBench/tree/c26e151ed601ba109dc4d35e057ff8e73fec469d) README 记录后续 verified split；报告涉及三次尝试取最佳时，不能拿我们的一次试验直接对比。代码与各任务数据、依赖许可证分别核验；其模型裁判、动态安装/执行、容器与数据取得未在当前授权下运行。

[MLAgentBench 论文 v2](https://arxiv.org/html/2310.03302v2) §2.1–2.3：作者把任务描述、起始材料、评价器与可用动作分开，并保存行动/响应/观察/工作区快照，评价任务结果和时间/token。其特定基准采用相对 starter baseline 的阈值，该阈值不能直接搬到我们的领域；Kaggle 等材料、模型/GPU及依赖另有准入条件。已只读查看 [官方仓库固定版本 5d71205](https://github.com/snap-stanford/MLAgentBench/tree/5d71205cc20a8e95d43aa7cb7120e89ca3323e31)，不称已运行或集成。

**对基线的具体改变：** 每个任务分别记录 (a) 正确执行和原工件，(b) 数据/方法/指标是否匹配问题，(c) 实际观察与竞争解释、负例和下一决定，(d) 人工/模型参与方式及总耗时、token、费用；未知值为 unknown。报告单次/多次与失败数，保持实际授权和原ID；不能用某篇论文的 best-of-three 或成功阈值装饰本项目的单次结果。对领域真实性需要适当专家或原始文献支持，不能从程序通过推断。

## 2. 失败经验需要比较，不是越短越好

[Negative Knowledge as Failure-aware Shared Memory for AutoResearch v1](https://arxiv.org/html/2606.21024v1) §2–3、附录 B/C（2026-06-19，预印本）：作者将完成尝试的失败按范围、程度和建议行动形成有界记录，分别比较无记忆重试、原始日志 self-debug、一次失败整理和多轮整理。其 38 项确定性评测子集报告：单条失败记录 36.8%，三轮原始日志 self-debug 44.7%，三轮深整理 47.4%；这是同一任务失败后的重试，不是跨课题迁移对照；这些是该论文条件/样本的作者结果，不是我们复现的成功率。44.7% 与 47.4% 在 38 题中约相差一题（17/38 与 18/38），不应据此声称稳健显著差异。更关键的是作者附录区分“下次看到的记忆长度”和**包含生成、失败尝试、整理、后续尝试的端到端成本**：深整理约 101k 中位 token，对照三轮 self-debug 约 56k；因此不能仅因短记录就声称整体更省。不同条件的尝试轮数不同，比较时须明确机会与费用而不是直接假设公平或因果。

已只读核 [官方仓库固定 commit 015ac48](https://github.com/hch-wang/Negative_Knowledge/tree/015ac48da8a9ebd2420ffee0f4f84bd5d1d8bbb9) 的 README、`negative_knowledge/curator.py` 与 MIT 根许可证。代码使用枚举区分失败层级、范围、程度与建议；受限静态审计及纯合成探针显示其现有 validator 不能证明描述真实，也未强制所有文本长度/类型/额外字段，不能直接作为证据验证器。curator 路径需要 Anthropic SDK/模型密钥，且可发送本地实验材料；未运行该路径、未复制代码、未接入。已按用户授权将该固定commit拉至独立新参考目录 `/workspace/reference-exploration-20261115/negative-knowledge-015ac48`，这不是缺失旧参考盘的恢复；本机审计 `runs/s075-reference/negative-knowledge-assessment.md`。论文样本、任务和模型有限，其 reported 效果不能推广到本项目；标签如“普遍失败”需要证据支持，不应由单次失败自动晋级。

**对基线的具体改变：** 原结果、适用条件、不利例和 unknown 先作为有来源的候选经验；操作者声明、模型实际看到、模型实际采用、行为/研究结果发生变化四者分开记录。若未来要评估价值，事前固定任务、材料、可用工具、模型、提示、尝试机会、评价器及总预算，比较无经验、原始失败记录及整理经验等相关条件；完整计入生成/整理/执行/恢复成本。若没有模型授权，只能做无模型的回放/评估设计或明确规则对照，不能宣称模型采用。S067 同臂保持 unknown，不能重开其预算来制造差异。

## 3. 自主程度与人参与要分别说明

[Agent Laboratory 论文 v2](https://arxiv.org/html/2501.04227v2) 描述人提供研究想法，在文献、实验、报告阶段可提供指导；其作者通过研究者反馈评估结果。我们只借鉴把人的介入及阶段工件显式记录，不把其论文自报的性能或成本直接迁移为本项目结果；原参考项目许可、依赖和实际运行仍以已有审计为准。

[AgentBench 论文 v3](https://arxiv.org/abs/2308.03688v3) 和 [官方仓库固定版本 d1e4a10](https://github.com/THUDM/AgentBench/tree/d1e4a10db08c87075c78972e48ecc182be03e2d5) 的交互式任务提示要分别记录环境、行动与失败；通用交互环境成功并不证明科学推理。论文原始环境与仓库后续版本范围有差别，依赖容器/外部资源，不应混合统计或在未审条件下运行。

**对基线的具体改变：** 每次真实闭环标注决定由人、确定性规则还是模型作出；按“原件/工具执行、反馈到决定、真实任务结果、跨课题迁移、隔离下自修改”分别报告达到与未达到。层次是沟通用证据分类，不替代 Master Execution Pack 的原阶段门。当前 S035 有受限模型试跑但复核未通过，S065/S067 有真实结果但不证明模型自主改计划，S072 是人工指定的合成工程闭环。

## 4. 针对下一研究切片的候选设计（尚未批准为具体研究方案）

- **先选题与授权核验：** 找到当前工作区可取得、来源/许可/费用明确且未占用旧预算的真实数据；先核问题、标签含义、样本独立性及已有预曝，保留原件/哈希。没有合适数据则标 unknown，不伪造课题或宣称盲测。
- **固定评价对象：** 明确原研究任务、竞争解释、目标指标与不利指标、候选与基线、输入/分组、计划改变或等待规则、可恢复行动和资源上限；由独立成员在任何新研究动作前检查。写明作者、执行者、评价者分工及人的实际介入。
- **提高可判别性：** 如果比较两条策略，提前固定是否需要在同一个可控评估动作内测两臂，不能先看 final 再改；同一策略选择仍只得同臂 unknown。不要把 S067 的已耗尽项目复开或让新目录重置其额度。
- **最小真实验收：** 原始 observation 可追至工件；引用的是当次观察；计划 v1→v2 的具体差异或等待理由可回查；预算和模型数真实记账；完成后由独立成员按原身份核查/恢复。真实研究收益、工程验证、主观判断分别标注。

这一候选尚无固定数据、课题、资源账本或结果，不等于已预注册和执行。资源不足、授权范围不符或标签/来源不清时仅完成可独立进行的设计与审计，不以新项目绕过历史上限。

## 5. 用已有真实证据校准指标选择

[S075](../execution/SPRINT-075.md)按先固定并发布的事后方案，仅重读 S065/S067 已保存的 validation 配对指标，变化方向为 TF-IDF−BM25，绝对差不超过 1e−12 按零处理。Hotpot 的100个问题中召回改善3个，其中2个的MRR下降；BoolQ 的200个问题中召回不变198个，其中24个MRR下降、12个上升。两任务不合并，也不把既有validation当隐藏集。该发现支持下一项协议事前同时记录覆盖与排序/不利例，而不支持据此宣称候选总体更好、模型学到了经验或迁移有效。原文及原工件边界见 S075。
