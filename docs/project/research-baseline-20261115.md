# 自主研究任务基线（2026-11-15）

状态：当前执行基线，按实际证据更新。该基线调整执行优先级和验收方式，不改写 [产品宪章](../execution/pack-v2/00-charter/PRODUCT_CHARTER.md)、[阶段门](../execution/pack-v2/06-roadmap/PHASE_DELIVERABLES_AND_GATES.md)或原始研究协议/预算。背景及独立挑刺见[聚焦审查](focused-review-20261115.md)。

## 首要目标与验收

围绕一个可追溯的真实问题，在现有 ResearchProject/Controller/Workbench 中完成可接续的研究：问题和假设 → 明确方法、数据、评价及预算 → 实际行动和证据 → **依据具体结果修订下一计划或说明为何等待** → 用原身份接续，由独立成员回查。明确等待可构成本轮有价值进展；完整 G1 仍须满足至少两轮、真实观察导致有依据的计划变化和另一成员接续等原门槛。成果必须能指向具体输入、代码、原行动、观察、计划差异、预算和恢复状态；如果未执行或反事实缺失，标记 unknown。受监督工程演示、经验被引用、模型自评、单元测试和多代理数量均不能单独证明自主研究收益。

优先验证真实反馈是否改变了下一决定，而不是继续扩展与目标无关的显示、包装或新抽象。某次模型是否实际采用经验，应结合原上下文、回复、实际被采纳的决定和引用核验；引用或自报本身不足。若要证明经验导致决定改变或策略带来收益，则需合适的可区分对照。模型费用/调用限制尚未授权的部分不得擅自扩大。同臂、仅一臂或未执行时不把结构性零差当成收益或无收益证明。有效负结果也要保留。

## 调研补充：如何衡量研究推进

[外部方法调研](baseline-research-20261115.md)据 ScienceAgentBench、MLAgentBench 和失败经验研究，要求分别衡量实际执行、任务/领域结果、真实反馈到下一决定、模型/人实际参与、跨任务效果及包括整理在内的总成本。一次成功、一次被引用、短记忆或测试通过均不足以证明自主研究收益；同臂/未测反事实仍为 unknown。下一个真实课题先固定来源、评价、预算、竞争解释和恢复方式，具体方案及原阶段门不被本调研自动替代。

## 当前执行顺序

1. **安全收口 S074 在途工作**：不扩大 UI/恢复范围。保留未提交工作和本机 checkpoint-003；只完成必要的原 body/原 ID、两个崩溃窗口、来源漂移、多 pending/旧无正文、跨项目与浏览器/后端验证及独立审查。旧无原文为 unknown；成功后再提交，否则保留原件及精确恢复状态。它是保护现有工作的前置事项，不以检查数量作为目标。
2. **选定并登记真实研究切片**：在用户既有受信本地授权、可核预算和可用材料内，先固定问题、来源、假设/竞争解释、评价、资源上限、停止及恢复方式；不得重置旧课题额度。优先从可回查的已有研究观察出发，但不重跑耗尽的项目。保留失败与不利样本。
3. **执行并独立核对反馈闭环**：证明真实观察如何改变计划或为什么等待，验证原身份与累计预算。独立复核须回查实际数据与工件，明确是否只有人工作决定，不能把工程 fixture 或模型自评冒充真实研究自主性。
4. **只有可区分时才做经验/策略对照**：事前固定同材料/预算的比较及指标，检查候选是否实际影响决定。若同臂、缺另一臂或行动未执行则结果 unknown；负结果亦可作为结论，不自动晋级。
5. **交付与组织按结果调整**：围绕当前研究增量处理可复现、来源与实际可取交付，不为流程扩张重复建设。没有凭据或原文件证据时不假称附件或跨机恢复成功。

## 团队组织与工作方式

主负责人负责研究目标、预算与原项目身份、集成、发布和向用户解释结果；`engineering` 负责 S074 现有实现及研究执行所需最小实现；`capability_review` 不参与同一实现，负责研究协议、来源/算术、负结果与独立验收。两名现有成员按需复用，可兼任相邻工作；单一文件一个 writer。可并行只读调研与独审，但同一工作树由单一会话 owner 持有协作 lease；root明确授权的团队成员共享同一 owner，并遵守单文件 writer、写入/执行前 heartbeat 和长步骤续租；由负责人统一 release。若其他 owner 活跃，本轮只读。lease 不提供 OS 锁，也不能强制终止过期执行者。需要其他专业能力时先查已有技能和参考；不为角色数量另建团队，默认总池不超过 10，服从宿主 7 并发上限；若确需新增优先用户偏好的 Terra/Luna。

每一轮只要求为当前真实目标选择有价值的验证。将**真实研究行动**、**工程合成行动**、**模型委派**及其预算分别记录；未测费用/token 保持 unknown。独立审查应指出具体证据和反例，不等同于 OS 隔离或可信时间戳。三小时触发用于对齐和报告，运行窗口内继续可做工作；窗口结束后不假称常驻或通知已送达。

## 既有边界

不得伪造旧盘或原项目恢复、改动冻结 evaluator、升级原 source pin，或以替换身份重置 pending/unknown 请求和历史预算；已获授权且核对原字节的复制、搬迁与同身份重开可以如实记录。用户已接受 Worker 隔离缺失，按受信本地范围工作，不重复询问；不声称 sealed、OS 隔离或多代 RSI 通过。不得新增采购、付费模型/API 或外发消息；仅按既有明确批准的切片使用模型和工具。新的付费/模型范围需要单独授权，但不阻止不依赖它的工作。
