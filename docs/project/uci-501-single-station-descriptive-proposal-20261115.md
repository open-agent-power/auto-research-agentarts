## 研究问题与来源

候选问题是在**一个事前固定的监测站和固定时间窗**内，描述逐小时 `PM2.5` 与 `TEMP` 的已保存配对观测，以及条件允许时的 Pearson 相关系数。UCI [Beijing Multi-Site Air Quality 数据集页面](https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data)和 [UCI 元数据 API](https://archive.ics.uci.edu/api/dataset?id=501)描述 12 个国家控制空气质量监测点、2013-03-01 至 2017-02-28 的逐小时数据，PM2.5 单位为 `ug/m^3`，TEMP 为摄氏度；`year`、`month`、`day`、`hour` 是时间字段，`station` 是空气质量监测点名称。页面将空气质量数据归于北京环境监测部门，并称气象数据匹配最近气象站；并不能据此假设两种测量来自同一位置。字段名、单位及其在拟选原文件中的实际含义仍须在数据准入前核准；未核准不建 Project。

这是一个**描述性、完整对相关分析**，不是气温对污染的因果估计、预测模型、天气校正、公共卫生或临床结论。季节、昼夜、自相关、节假日、排放、空间错配及其他共同原因可能产生或改变相关；本计划不推断独立同分布，不计算显著性、置信区间或因果效应。该课题不是检索任务，不能作为 S109 经验迁移或 BM25/TF-IDF 收益的检验。

## 固定质量门和关联分析候选

在获取任何观测值前，先固定质量条件、阈值、分支和未来 Controller ID 的登记方案；获准获取并完成 source 捕获与 Project 创建后，才在首次质量工具派发前实际登记，并认证原件。以下质量计数是机器一致性门，不是科研有效性或数据许可认证。拟对选定列声明 `PM2.5` 为 target、`TEMP` 为唯一 predictor，不设置组列；键为经定义核准的四个时间列。条件采用现有 `tabular-quality-conditions-v1` 且 AND：

- `rows >= 3`；`key.incomplete_rows = 0`、`key.duplicate_rows = 0`、`key.conflict_groups = 0`。
- 对 `PM2.5` 和 `TEMP` 各自要求 `numeric.finite >= 3`、`numeric.invalid_numeric = 0`、`numeric.nonfinite = 0`。

上述三个有限值只是原算法可计算的最低门槛，不是足够样本量或可代表性阈值。缺失 `NA` 会有声明缺失 flag，不能要求所有 flags 为空而错误排除所有合法缺失；仍须分别报告各列 finite、declared_missing、empty、zero、invalid 与 nonfinite。每列至少3个有限值**不能保证同一行至少3个完整对**，也不能保证非常数。

质量条件全部已知满足、完整时间核验通过且原身份/额度/候选核验均通过时，可在用户另行明确操作下，使用质量引用计划的现有显式 v2 策略选择原质量行动及结果绑定的 `data.numeric-association`；条件不满足则等待，unknown、丢失、漂移或不一致停查。`numeric_association_adapter` 对两列逐行只保留均为有限数的完整对，输出 `n`、`excluded` 及 Pearson r；完整对少于3或任一列常数时 r 为 null 并有明确原因，不得以0、0相关或“检查通过”替代。保存原始总体结果、缺失/排除和限制，不能把近站气象关联描述为因果、预测能力或独立效果。该机制已有受限 Python/HTTP 入口，页面是否覆盖完整真实操作须另测；不声称自动研究或自动模型判断。

另在接触数据前固定**公开描述门**：同一行两列均有限的完整对 `n >= 1000` 且 `5*n >= 4*rows`（至少 80% 原时点），同时 r 必须为有限数。1,000 与 80% 是本描述性任务的事前保守选择，并非有效样本量、自相关修正、代表性或统计显著性的保证。达不到时公开 `n`、`excluded`、总行数与“未满足预定描述门”，不公开或解释该 r，也不事后降低门槛。原生质量条件不能核配对交集；第二工具若已被授权并派发，仍可能在 `n >= 3` 时计算并在本地工件保留数字 r：此时是**公开/解释不合格**，不能谎称工具没有算出 r，也不能将已算出的值改写为 null。只有原生 `n < 3`、常数等导致未定义时，才如实报告 r 为 null 和原原因。公布前还须核实际报告/页面避免绕过该门；不能修改或删除原工件来强制通过。
