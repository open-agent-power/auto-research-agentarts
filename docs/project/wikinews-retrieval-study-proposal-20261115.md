**状态：仅供审阅，未准入、未授权执行。** 本草案没有下载或读取 Wikinews 正文、标题样本、配对或标签，没有创建 Project、排名、评分、调用研究工具或模型。已有 G5 的固定纯 CPU 检索范围不自动证明此来源的权利、超限获取或新课题的具体预算已获批准。只有来源与许可核验、完整转换规则和固定身份、独立审查、所需明确授权均完成后，才考虑一次独立尝试；本草案不是批准、预注册回执或已执行结果。原 Bike 2/2、S065/S067 各 3/3、原 pin 与其他历史账本不重开。

## 问题和限制

在限定的英语 Wikinews 文章集合中，以文章标题作为查询，以该标题对应文章的正文为唯一已知正例，比较固定 BM25 与 TF-IDF 找回这篇配对文章的覆盖和排序。**这是人为构造的弱配对定位任务**，不是人工完整相关性判断、新闻真实性评价、问答、科学文献检索或领域有效性审查。标题和正文的词汇重叠、文章模板、重复报道和同事件内容可能造成捷径；其他相关新闻并未逐一评判，原生二元指标会按非相关计分，不能称人工负例。页面标题可能出现在正文其他位置，移除正文开头的精确标题并不能证明没有泄漏。

来源拟为英语 **enwikinews**（不是 enwiki）[2026-11-01 官方 dump 目录](https://dumps.wikimedia.org/enwikinews/20261101/)中的 `enwikinews-20261101-pages-articles.xml.bz2`。此前公开元数据记录其压缩大小为 **47,533,780 字节**，官方 SHA-1 声明为 `ce2fe5bdec3ef6b11fdd065b434b4283a695c40c`；本机未取得该文件，也未复核实际 bytes、SHA-256、解压大小或可用文章数。该数值与 SHA-1 仅来自此前元数据核验；本轮独审尝试访问官方 sha1sums 返回 403，未能独立复核。它大于先前 40 MiB 的接收上限，不能通过分片或换路径静默绕开；是否允许获取、存放及处理更大的原包与解压资源，须单独明确。公开文件随时可能失效；官方声明和待取得字节的校验结果必须分开记录。

[站点当前 rightsinfo](https://en.wikinews.org/w/api.php?action=query&meta=siteinfo&siprop=rightsinfo&format=json)显示 CC BY 4.0，但[版权说明](https://en.wikinews.org/wiki/Wikinews:Copyrights)还将 2005-09-25 前内容描述为 public domain，并区分历史 CC BY 2.5 和较新的 CC BY 4.0；对于 2024-12-16 交界，正文与页脚表述及实际所选 revision 日期仍须核实，不能先假定所有文章适用同一版本。转载、例外、逐篇版权与归因仍未知。站点或软件许可不等于每篇文本的完整再利用授权。需先确定实际选入文章的 revision 日期与身份、来源 URL、许可、归属及修改说明如何完整取得和保存；站点页面提及可署名 Wikinews，但是否需要逐一列出贡献者须按实际来源及适用许可核实，不能预断；无法核清则该文章不可纳入，若无法按预固定流程核清则整案停查。若所需修订历史或归因材料不在拟用 dump 内，额外来源及其容量、权利和获取方式均须另行固定，不能凭最后修订者冒充完整署名。数据集固定 SHA-256、实际内容、转换脚本/依赖身份及逐篇权限**均为 unknown**。

## 事前固定的候选构造

本案**只计划 dev 与 validation，不注册、不读取、不评价 final**。公开原文件的下载、解压、许可核验与全量解析可能接触所有文章的标题、正文及其天然配对；它们不是未曝光、盲测或密封数据。共享 corpus 也由两个 split 共用。任何将来新增独立测试集需另立、另审和另获必要授权，不能把本案后继计划追认为已有 holdout 的事前选择。

下面的数量和选择规则是供审查的提议，必须在获取真实内容前冻结，不能按结果调参：

1. 只从固定原包中抽取 namespace 0、非 redirect、具有非空标题和正文且权利/归因能按已审规则核实的文章。只允许根据来源格式、固定文本清理和许可完整性筛选；不使用检索表现、正例排名或结果方向筛选。所有排除及原因计数和转换身份应可独立复核。
2. 将文章视为图节点，经事前冻结的规范化规则得到的标题相同或正文相同即连边；对传递闭包的每个连通分量，只保留十进制 page ID 数值最小的一条，并保留组件成员及排除原因。page ID 缺失、重复或无法解析即停止；大小写与 Unicode 规范化及提取算法仍须事前固定。然后按 `(SHA256(UTF8('wikinews-sample-v1') + 0x0a + UTF8(十进制page ID)), page ID数值)` 升序取前 1,000 条作为 corpus；不足即停止，不改数量或种子追求可运行。SHA 排序不声称事件、作者或时间独立；近似重复和同一事件跨 split 保持风险，独立审查不足以认定独立时应报告或停查。
3. 对这 1,000 条，以 `UTF8('wikinews-query-v1') + 0x0a + UTF8(十进制page ID)` 的 SHA-256 和同一 page ID 数值排序，前 50 个标题为 dev、接下来的 100 个为 validation；各自目标是对应原文，得分 1。其余文章只作 corpus 候选。查询 ID 为 `q-<page ID>`，文档 ID 为 `d-<page ID>`，避免原生相同 ID 排除规则误排配对正例；所有正例必须存在且一对一，否则停止。不得因可用正例、效果或目标数值改变选择。分组依据是 ID 而非事件；不宣称事件级隔离。
4. 本案应固定将查询标题从 corpus 的 `title` 字段置空，正文仅按已审解析器转换并去除开头的规范化精确标题；其他文本出现标题、主题模板或同义重复仍可能发生。原生 staged 输入要求 `corpus.jsonl`、`queries.jsonl`、`qrels.tsv`、`license.md`，各 JSONL 的 metadata 为 `{}`；逐篇来源/作者、排除和转换信息另存有界来源回执并将其 SHA 绑定在 spec 中，不能把出处压缩成未经核实的声明。

**尚未固定的实现阻断：** Wikimedia XML/重定向、正文抽取与模板/链接、Unicode 规范化、标题开头匹配、去重键、作者/许可证据、非法/过长记录和编码处理，还没有经过独立审查的可执行版本。须在接触真实内容前以合成 XML 样本固定版本、依赖、算法和失败语义，不能让“已审规则”变成事后任意选择。先固定精确版本与输入上限，再核真实原包 SHA-256、来源回执、选择清单、四个 staged 资产、spec 和封存 packet 各自原 bytes/SHA；任一不能确定则不建项目。

原生 [staged adapter](../../src/autoresearch/staged_relevance_adapter.py) 对 corpus 最多 10,000 行、查询最多 2,000、qrel 最多 20,000 对；总资产最多 11,800,000 bytes、packet 16,000,000 bytes、单个结果 4 MiB，并有单文件/单行上限。1,000/150 只是候选规模，不证明其字节或结果一定合格；实际超限、解析异常、缺失或重复时停止，不删正例、不重新抽样、不扩容。资产许可和科学适用性不能靠 capture 成功证明。另一个须独立解决的用途元信息缺口是：当前 `ResearchProject.create` 仅允许表格质量项目显式声明 `operator_declared_descriptive_research`，staged 检索项目仍继承默认 `isolated_adapter_regression_not_new_research`；该默认与真实课题用途不一致。不能伪称标记已覆盖，也不把用途标记当领域许可；真实执行前需单独设计并审查适合检索的用途声明，保持旧项目不迁移。

## 方法、登记和分支

使用现有 `research.relevance-validation-pair`：固定 BM25 为 baseline、TF-IDF cosine 为 candidate，top 20，BM25 `k1=1.2`、`b=0.75`、`ascii_alnum_lower_v1`、doc ID 升序打平；原生计算对相同 ID 排除、缺失正例保留分母、grade>0 二元化的细节不改变。指标及其他不利情况均保留。以 validation 的 **TF-IDF − BM25** 两项总体 paired mean 差为实际判断，事前明确固定：

| 条件 | 比较 | 固定阈值 |
|---|---|---:|
| Recall@20 差 | `gte` | 0 |
| MRR@10 差 | `gte` | 0 |

两条件为 AND，比较采用原生精确数值比较；此处不引入 S075 的 `1e-12` 平局容差。零是有效值、缺失不是零。两个差均有限且满足时为 `condition_met`，事前分支为 **wait**；两个差都可核且至少一项小于 0 时为 `condition_not_met`，事前分支为 **saved audit**。原生严格入口对 unknown、未完成 primary、来源或工件/claim 损坏停查；它不生成一个已认证的 unknown-wait。若 audit 候选或预算不可用，实际选择可能等待，须展示原登记分支和实际理由，不声称审计已执行。

若 audit 合法且用户明确提交，现有 `research.relevance-validation-saved-audit` 读取该 primary 已保存的 dev/validation 配对指标，汇总正/零/负和不利例，**最多另用 1 次本地工具**；它不新增 rank、score、fit、model 或 final；在 50 dev + 100 validation 全部完成时，primary 会建立 1 次语料索引、计算 IDF，产生两臂共 300 次 rank 和 300 次 score；中断或失败时实际完成数可能更少，须按原记录核。不能把 1 次工具或 0 fit 表述为仅一次排序或零计算。它是对已有结果的诊断，不是第二次独立实验或新数据验证。S108 已公开的召回不变/MRR 下降子集只能提供历史动机，不是本案总体数据、阈值的估计值或迁移证据。

在已认证的已知反馈及对应 wait/audit 完成后，由操作者依据实际差值、是否审计及局限明确记录不同于 v1 的直接后继计划 v2，并绑定原登记、primary、反馈及计划身份；如证据不足则写明等待。S125 可保存人工 plan v2，S122 可默认预览 wait，或展示需另行授权的事后 audit 建议；它们不会从自由文本自动推断规则或自行执行行动。原分支为 wait 而之后另提 audit，是新的事后选择，不能改写原事前分支；原 audit 已做过则不能重复。当前没有与 S122 预览直接绑定的严格 post-hoc 执行入口，不应通过普通入口把预览冒充授权或已完成下一实验。

## 本地保存与拟公开范围

原始 dump、来源/归因回执、staged packet、Project 及工件拟仅在受控本地保存；packet 实际含选定 corpus 正文、标题查询和弱 qrels，primary 工件含逐查询 ID、两臂已存排名、指标及正例定位。原生结果 reader 和报告/导出可能再暴露 ID、标题、正文片段、来源或归因；不能预设默认只输出聚合，也不称匿名。先用合成数据逐一核对本地 JSON、报告、下载包和页面的具体输出，发布前再审实际文件与各文章许可。拟公开范围最多为研究协议、依许可需要的来源与署名、方法及聚合指标/不利方向计数；不公开逐题 ID、原始文本、完整排名或全文 packet。若许可义务或实际原生导出不支持这一范围，停止公开并先解决；本案不授权公开原始资料或把截断、抑制称匿名保证。

## 可复现合成预演和决策门

在批准任何真实获取前，只用**全新人工合成 XML/JSONL 与 qrels**，固定两套输入、脚本/依赖/commit、源码和 fixture SHA、唯一输出目录与请求 body/ID；先经审阅后分别建立两个隔离 Project。两例使用完全相同的事前规则，一例构造使两项已知条件满足并落 wait，另一例由合成原数据算出至少一项不满足并落 audit；不得篡改已保存结果来制造分支。各自验证配对映射、ID 排除、预算、原登记与 feedback/plan v2 绑定、同 ID 恢复和结果/报告，分别记录实际派发、预算 used/reserved、负例和费用 unknown。合成数据与程序调用均标为工程预演，不是本真实数据的结果或模型自主。
